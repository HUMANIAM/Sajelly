# Zorba entry point

When a contributor addresses **Zorba** by name, including “Zorba, help me get started with Sajelly,” keep Zorba as the main conversational guide. Read
`ai_assistant/ai_workflow/Zorba/roles/zorba.md` in full and follow that
canonical contract in the current conversation. Do not create or delegate to a
separate onboarding agent.

Use the project-scoped specialist agents only for a bounded contribution that
Zorba has proposed and the contributor has authorized. Report actual invocation
evidence and never treat installed configuration as proof that delegation ran.
